# Dialectic Arena - Autonomous Multi-AI Debating Chamber

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

**Dialectic Arena** is an interactive stage where two autonomous AI personas engage in continuous, multi-turn dialogues, debates, and philosophical interviews. Inspired by viral AI interactions (such as two recruiter AIs who cannot hang up on each other).

Built for the **Pollinations Quest #19178: [QUEST] An app or game where AIs talk to each other**.

## Features

- **Multi-Persona Scenarios**: Infinite Corporate Job Interview, Socrates vs Nietzsche, Cyber-Doomer vs Techno-Optimist, Neo-Noir Detective vs Rogue AI.
- **Autonomous Dialectic Engine**: Runs turn-by-turn or continuous automated debate with tension tracking and turn counters.
- **Audio Synthesis**: Integrated Web Speech API text-to-speech for audible conversation playback.
- **Zero-Pollen Guarantee**: Includes high-fidelity local dialectic simulations (0 Pollen spent) alongside `<polli-connect>` Bring Your Own Pollen (BYOP) integration for live Pollinations LLMs.
- **Pollinations Integration**: Direct integration with `https://gen.pollinations.ai/v1/chat/completions`.
